
# SWYNEX Task 2: Simulated Device Data

## Project Overview
This project generates simulated IoT sensor readings with timestamps and stores them in a CSV file.

## Features
- Generates 20 simulated sensor readings.
- Records timestamp and device ID.
- Simulates temperature, humidity, and voltage readings.
- Stores readings in CSV format.
- Prints generated readings to the console.

## Technologies Used
- Python
- CSV
- Random
- Datetime
- Pathlib

## How to Run
1. Install Python 3.
2. Download `simulated_device_data.py`.
3. Run the command:

```bash
python simulated_device_data.py
```

The script generates `simulated_device_data.csv` in the current directory.

## Note
All readings are simulated for demonstration purposes. No physical IoT sensors are connected.
